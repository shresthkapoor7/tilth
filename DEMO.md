# A 90-second Tilth demo

## Before presenting

- Confirm Railway or local server uses `gpt-6-astra` and the generation budget is available.
- Use a dedicated demo browser profile so personal saves are untouched. Create your character ahead of time. Keep one completed generated errand region for a reliable gameplay example; label it as saved content.
- Set sound volume and test optional Read aloud on the actual demo device. Browser narration is separate from Astra text generation.
- Rehearse navigation on your viewport. A new area still needs a real API call; never claim an unseen wish was precomputed.

## Route

**0–12 seconds — The premise.** “This world remembers what I do. I ask the witch for the next place, and Astra decides how that wish should turn out.” Show a weapon attack/roll and the journal.

**12–30 seconds — A real action.** In a saved region, accept an errand and move its marked boulder or deliver a parcel. Show the physical change and its journal entry. Explain that the target and action are real game objects, not only dialogue.

**30–45 seconds — The wish.** Approach an unexplored edge. The greeting may already be ready. Ask: “A quiet forest village where people need help, with supplies to deliver.”

**45–70 seconds — The interpretation.** While the live spell runs, explain the separation: Astra writes the region, tasks and judgment; the engine verifies and executes them. Read the witch's response and enter when ready. If generation takes longer, narrate the architecture and extend the demo honestly.

**70–90 seconds — Proof.** Show the new place, named houses and task objects. Talk to a resident and accept the quest. Point out the marker and the specific parcel recipient. End on: “The next wish gets this new history too.”

## Optional darker branch

On a separate run, strike an unprotected townsperson such as Clover, then ask for “a peaceful road.” Show the recorded hit and the witch's reaction. A hostile interpretation can ignite footsteps after a warning or increase patrol detection. Astra may choose mercy; do not promise a predetermined judgment or fabricate wrongdoing for the live run. Saved hostile content is useful for showing the mechanic, but clearly identify it as a prior generation.

## If the API is unavailable

Show the visible error and retry control, then demonstrate the previously saved region. Say explicitly that the live request failed. Saved gameplay remains usable; it is not a substitute presented as a fresh Astra response.
